# Faisal Hossain — GitHub Pages Landing Page

A responsive personal landing page built with plain HTML, CSS, and a tiny bit of JavaScript.

## Publish for free

1. Create a **public** GitHub repository named exactly `faisalbd92.github.io` under your `faisalbd92` account.
2. Upload `index.html` to the repository root and commit it to the default branch (`main`).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Wait for GitHub Pages to deploy. Your site should be available at `https://faisalbd92.github.io/`.

## Custom domain

If you want to use `faisalbd92.is-a.dev` later, add it in **Settings → Pages → Custom domain** and configure the DNS/CNAME according to the is-a.dev instructions. Do not set a custom domain until the DNS record is configured correctly.

## Personalize

Edit the text and links in `index.html`. The GitHub links currently point to `https://github.com/faisalbd92`.
